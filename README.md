# CRC Berechnungstool

**Current version:** v2.0

Tool zur Berechnung von Prüfsummen für:
- CAN
- CAN FD
- LIN
- FlexRay

Im Rahmen einer Projektarbeit an der Hochschule Landshut entwickelt.  
Der Quellcode wird unter der **MIT-Lizenz** bereitgestellt.

## Download
Die Windows-Anwendung (EXE) ist über **GitHub Releases → v2.0** verfügbar.

## Versions
- **v2.0** – aktuelle Version (Hauptverzeichnis)
- **v1.0** – archivierte Version (`/archive`)
