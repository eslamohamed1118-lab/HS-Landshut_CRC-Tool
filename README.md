# CRC Tool (Qt 6 / C++)
Tool for calculating and verifying CRC checksums for automotive bus systems:
- CAN (Classical CAN)
- CAN FD
- CAN XL
- LIN
- FlexRay
- Ethernet

## Technologies
- C++
- Qt 6 (Qt Creator)
- CRC++ Library

## Authors
- Eslam Mohamed
- Sassi Nesrine

## Usage
1. Clone this repo into Qt Creator.
2. Build and run the project.
3. Use the GUI to input message data and calculate CRCs.
